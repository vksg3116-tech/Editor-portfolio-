# Vivek — Video Editor Portfolio

A responsive, single-page creative portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation interaction

## Customize before publishing
1. In `index.html`, replace `your.email@example.com` with your contact email.
2. Replace the four demo project cards with real project names, thumbnails and video links.
3. Add your social profile links if you want them displayed.
4. Update the About section so it accurately describes your experience and tools.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `vivek-portfolio`).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Your site will appear at `https://YOUR-USERNAME.github.io/vivek-portfolio/` after deployment finishes.
